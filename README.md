# Altınsoy Ailesi paneli

Aileye özel, arama motorlarına kapalı Next.js paneli.

## Geliştirme

```bash
npm run dev
```

Tarayıcıda `http://localhost:3000` — aile PIN: **1905**

## Sayfalar

- `/` Aile paneli (takvim, günün öne çıkanları, hızlı bağlantılar, günün sözü)
- `/cocuklar/nilufer` ve `/cocuklar/seref-ali` program, ödev, sınav
- `/lgs` geri sayım, net grafiği, eksik konular
- `/galeri` albümler
- `/hafta-sonu` aktivite önerileri
- `/ogretmen` Meryem Öğretmen köşesi
- `/yemek` menü ve alışveriş
- `/yildizlar` görev / harçlık puanı
- `/arsiv` WhatsApp not arşivi
- `/ebeveyn` form ile ödev ekleme

Veriler tarayıcı `localStorage` içinde tutulur.
